## Mini-projet Git / DevOps – Compteur front-end

Ce dépôt contient un mini-projet **front-end** très simple, idéal pour s'exercer au workflow Git / GitHub (branches, PR, revues de code).

### Contenu du projet

- `index.html` : page principale avec un petit compteur.
- `style.css` : styles pour donner un rendu moderne.
- `script.js` : logique JavaScript du compteur (incrémenter, décrémenter, reset).

### Lancer le projet en local

1. Cloner le dépôt :
   ```bash
   git clone https://github.com/HiXaM94/Git_DevOps_Proj.git
   cd Git_DevOps_Proj
   ```
2. Ouvrir `index.html` dans un navigateur (double-clic ou via un petit serveur local).

### Idées d'exercices collaboratifs

- Ajouter une limite max/min au compteur.
- Ajouter un thème clair/sombre.
- Enregistrer la valeur du compteur dans le `localStorage`.
- Améliorer le design ou le texte.

Chaque changement peut être fait sur une branche `feature/...` puis mergé via une Pull Request sur GitHub.
