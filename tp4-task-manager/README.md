## 🌐 Demo

**[🚀 Voir la démo en ligne](https://HiXaM94.github.io/Git_DevOps_Proj/tp4-task-manager/)**

## 🛠️ Technologies

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Testing**: Jest
- **Linting**: ESLint
- **CI/CD**: GitHub Actions
- **Deployment**: GitHub Pages
- **Dev Server**: lite-server

## 🚀 Fonctionnalités

- ✅ Ajouter des nouvelles tâches
- 🗑️ Supprimer des tâches
- 🔄 Marquer comme terminée / à faire
- 🔍 Filtrer (Toutes / Terminées / Actives)
- 📊 Compteur de tâches restantes
- 🎨 Interface Glassmorphism

## 🛠️ Installation

1. Cloner le projet :
   ```bash
   git clone https://github.com/HiXaM94/Git_DevOps_Proj.git
   cd Git_DevOps_Proj/tp4-task-manager
   ```

2. Installer les dépendances :
   ```bash
   npm install
   ```

3. Lancer le projet localement :
   ```bash
   npm start
   ```

4. Lancer les tests :
   ```bash
   npm test
   ```
