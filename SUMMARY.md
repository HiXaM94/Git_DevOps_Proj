### 1. Vérifier sur GitHub (2 minutes)

**Vérifications :**
- ✅ Les fichiers sont bien présents
- ✅ Les branches sont visibles (onglet "Branches")

### 2. Créer les Issues (5 minutes)

📍 **GitHub → Issues → New issue**

Créer 3 issues selon les modèles dans `GITHUB_GUIDE.md` :
1. `feat: Ajouter une section contact`
2. `feat: Mettre en place un système de logs`
3. `fix: Corriger le responsive du footer`

### 3. Créer le Project Board (3 minutes)

📍 **GitHub → Projects → New project**

- Template : **Board**
- Nom : `TP2 - Gestion des tâches`
- Colonnes : To do, In progress, Done

### 4. Créer une Pull Request (15 minutes)

**Exemple avec feat/contact-form :**

```bash
# 1. Se placer sur la branche
git checkout feat/contact-form

# 2. Créer un fichier exemple
echo "<!DOCTYPE html>
<html>
<head><title>Contact</title></head>
<body><h1>Contact Form</h1></body>
</html>" > contact.html

# 3. Commiter
git add contact.html
git commit -m "feat(contact): add basic contact form"

# 4. Pousser
git push origin feat/contact-form
```

Puis sur GitHub : **Compare & pull request**
