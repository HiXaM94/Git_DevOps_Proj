# TaskMaster Pro (TP4) 📝

Application de gestion de tâches moderne et responsive, réalisée dans le cadre du TP4.

## 🚀 Fonctionnalités

- ✅ Ajouter des nouvelles tâches
- 🗑️ Supprimer des tâches
- 🔄 Marquer comme terminée / à faire
- 🔍 Filtrer (Toutes / Terminées / Actives)
- 📊 Compteur de tâches restantes
- 🎨 Interface Glassmorphism

## 🛠️ Installation

1. Cloner le projet :
   ```bash
   git clone https://github.com/HiXaM94/Git_DevOps_Proj.git
   cd Git_DevOps_Proj/tp4-task-manager
   ```

2. Installer les dépendances :
   ```bash
   npm install
   ```

3. Lancer le projet localement :
   ```bash
   npm start
   ```

4. Lancer les tests :
   ```bash
   npm test
   ```
